# kl057 パッケージ案 初見判定（エマ）

立場: 60代、小さな会社の経営者。ホーム画面でタイトルとサムネを一瞬見て、押すか決める。

## 案1
タイトル: 店の看板は検索からAIの中へ？ ChatGPTに「店の窓口」（11月時点）

1. **何の話か:** 店の探し方が、ネット検索からChatGPTに変わっていくという話らしい。
2. **クリック度: 3**。気にはなる。ただ「看板」も「窓口」もたとえ話で、何が起きたのかがつかめない。
3. **期待すること:** ChatGPTに店が載る新しい仕組みができたのか。うちの店も載れるのか。
4. **誤解しそうな点・分からない言葉:**
   - 「看板がAIの中へ」は、文字どおりに取ると何のことか分からない。サムネの見出しが二つともたとえなので、具体的な中身が一つも残らない
   - 「店の窓口」が何を指すのか分からない（問い合わせ窓口？ 予約？ 売り場？）
   - 最初の台詞は「OpenAIは言う」で、会社の主張から入る。「本当かな」と思わせる効果はあるが、自分にどう関係するかは出てこない。OpenAIを知らない人もいる（ChatGPTは知っていても、作った会社の名前までは知らない）

## 案2
タイトル: ChatGPTに店の公式ページ。お金を出した店が勧められる？（11月時点）

1. **何の話か:** ChatGPTに店のページが作れるようになり、それが広告のように、お金を払った店ばかり勧められる仕組みではないかを確かめる話。
2. **クリック度: 4**。経営者がまず気になるのはそこ（「結局、金か」）。疑いの言葉がそのまま自分の本音なので、つい押したくなる。
3. **期待すること:** お金を払えば上に出してもらえるのか、払わない小さな店にも出番はあるのか、に「はい／いいえ」で答えてくれること。
4. **誤解しそうな点・分からない言葉:**
   - 「公式ページ」は、ふつうのホームページのことかと思ってしまう。ChatGPTの中にあるページだとは分かりにくい
   - 疑いの向きが強いので、「お金次第でした」という暴露話を期待してしまう。そうでない結論なら、見終わって「話が違う」と感じるかもしれない
   - 沙織の最初の台詞は、それまでの話を受けた言い方（「結局〜じゃない？」）。いきなり聞くと、何について「結局」なのかが一瞬分からない

## 案3
タイトル: AIに選ばれる店になるには？ ChatGPTに店が自分で値段を入れる時代（11月時点）

1. **何の話か:** ChatGPTに店が自分で商品の値段や情報を登録できるようになったので、AIに紹介してもらえる店になる方法を教える話。
2. **クリック度: 5**。「〜になるには？」は自分の商売にすぐ役立ちそうで、一番押したくなる。最初の台詞も、何ができるようになったかを具体的に言っている。
3. **期待すること:** うちのような小さな店でも登録できるのか、費用はかかるのか、何を入れればAIに選ばれやすくなるのか、という手順とコツ。
4. **誤解しそうな点・分からない言葉:**
   - 「選ばれる店になるには？」は手引き（ハウツー）を約束しているように聞こえる。中身が「どこまで来たかの確認」なら、期待とずれる
   - 「値段を入れる」は一瞬「値段を決める？ 値上げ？」と読み違えそう。「商品と値段を登録する」の意味だと分かるまで少し間がある
   - 日本の店でも今すぐ使えるのかが分からない。ここが期待の中心になる

## 案4
タイトル: ChatGPTが店の紹介回数を見せる。検索の次の「看板」はどこ？（11月時点）

1. **何の話か:** ChatGPTが自分の店を何回紹介したかを、店側が数字で確かめられるようになったという話。
2. **クリック度: 3〜4**。「何回出たかが分かる」は具体的で、経営者として気になる。ただタイトルの前半と後半で話が二つに分かれていて、焦点がぼやける。
3. **期待すること:** その回数をどこで見られるのか、それを見て何ができるのか（宣伝の効果を測れるのか）。
4. **誤解しそうな点・分からない言葉:**
   - サムネの「店に見える」が「店のように見える」と読めてしまう。「店側が見られる」の意味だと伝わりにくい
   - 後半の「看板」はかぎかっこ付きのたとえで、前半の具体的な話とつながらない
   - そもそもChatGPTが店を「紹介」していること自体を知らない人には、話が一段飛んでいる

## 案5
タイトル: 買い物相談は検索からAIへ？ ChatGPTの「店の案内役AI」はどこまで来た（11月時点）

1. **何の話か:** ChatGPTの中で、それぞれの店が用意した質問対応のAIに相談できるようになったという話。
2. **クリック度: 2〜3**。「店のAIに相談」は、もうあるチャットの自動応答と同じに聞こえて、新しさを感じにくい。
3. **期待すること:** そのAIがどこまで本当に役に立つのか、うちの店でも置けるのか。
4. **誤解しそうな点・分からない言葉:**
   - 「案内役AI」が、ChatGPTそのものなのか、店が作ったAIなのかが分かりにくい
   - サムネの「店のAIに相談する時代」は客の側の話に聞こえる。経営者の自分の話だとは思いにくい
   - 「どこまで来た」という言い方は良い（誠実な確かめ方の感じがする）

## 案6
タイトル: 検索で探す時代の次は？ ChatGPTに店が名乗り出る仕組み（11月時点）

1. **何の話か:** 店がChatGPTに自分から情報を出して、見つけてもらえるようにする仕組みができたという話（たぶん）。
2. **クリック度: 2**。全体にぼんやりしていて、何が新しいのか、自分に何の得があるのかが見えない。
3. **期待すること:** 「名乗り出る」とは具体的に何をすることなのか、の説明。
4. **誤解しそうな点・分からない言葉:**
   - 「名乗り出る」は、事件で「犯人が名乗り出る」のような印象がある。前向きな仕組みの話に聞こえない
   - サムネの「検索の次は / AIの中」は抽象的で、目が止まらない
   - 沙織の最初の台詞（「看板と検索で見つけてもらうものじゃないの？」）は自分の感覚に近く、入りとしては悪くない。ただタイトルとサムネが弱いので、そこまでたどり着かない

## まとめ

**クリックしたい順（上位3案）**
1. **案3**: 「選ばれる店になるには？」が自分の商売の得にまっすぐつながる。最初の台詞も具体的
2. **案2**: 「お金を出した店が勧められる？」が経営者の本音の疑いそのもの。結論が気になる
3. **案4**: 「紹介された回数が見える」が具体的で新しい。ただサムネの「店に見える」は読み違えやすい

**一番つまらなそうに見える案:** 案6
- 「名乗り出る」「検索の次は／AIの中」と、ぼんやりした言葉とたとえばかりで、何が起きたのかも、自分の得も分からない
- 「名乗り出る」には後ろ向きな響きもある
- 案1も、たとえ（看板・窓口）だけで中身が見えない点が同じ弱点

**どの案にも共通して気になること**
- 日本の小さな店でも今使えるのか、お金はかかるのか。分からないのはここで、見る理由もここ。案3や案2でこれに答えられるなら強い
