# kl057 初見レビュー（差分 4周目）

対象: 直したシーン5・6・7・9・11・12の台詞だけ。前後の直していないシーンは読んでいない。

## 1. 前回の指摘が直ったか

### 指摘1（シーン5・12）「ネットの店」と「町の店」の区別 → 直った（少しだけ残る）
- 「ネットで注文を受けて売っている店」と「お店に来たお客さんに売る、町の店や飲食店」と、どうやって売っているかで分けたので、耳で聞いても区別がつく。シーン12でも同じ言い方をくり返していて、ぶれていない。
- 残るのは2点。(a) 店を構えていて、ネット注文も受けている会社はどうなるのか（両方に当てはまる）。(b) ホームページはあるが、ネットで注文は受けていない会社（うちのような会社）は「町の店」の側なのか。(b) は聞けば「たぶん町の店の側＝今はアメリカだけ」と分かるが、シーン11の「申し込めるのは、店のサイトがあって、…本人確認が通る事業者」を聞くと「サイトがあれば申し込める」と受け取りそうになる。→【できれば】に入れた。

### 指摘2（シーン11）28日分の数と「ちらっと出ただけなら数えない」の食い違い → 直った
- 沙織の「申し込めることと、答えに使われることは別よ」を受けて、大輔が「サイトが何回参考にされて、何回押されたか」で確かめられる、と返している。シーン7の「サイトを参考にしたときだけ1回と数える」「ちゃんと答えに使われた回数なのね」とつながっていて、逆には聞こえない。

### 指摘3（シーン12）判定の問いが「もう申し込める」と合わない → おおむね直った（少し引っかかる）
- 問いが「日本の店が実際に登録して、AIの答えで見つけてもらう形」になり、「申し込める」と「実際に登録して使われる」の違いは分かる。沙織の「日本の店が登録と本人確認まで進めた例をまだ確かめられていない」で、何を待っているのかも分かる。
- ただ、直前の大輔の「日本で始まるなら、ネットで注文を受けて売る店から」は「まだ始まっていない」と聞こえ、少し前の「もう申し込める」と合わない（下の【直す】2）。また、問いの後半「AIの答えで見つけてもらう」の部分には、二人とも触れていない（【できれば】）。

### 指摘4（シーン7）越え方が困りごとと合わない → まだ引っかかる
- 困りごとは「看板の名前ではなく、登記した会社の名前が勝手に入って、直せなかった」。越え方は「看板の名前が複数あるなら、名前ごとに別に登録する」「会社の名前と看板の名前が違う店は、そこを知ってから申し込めばいい」。
- 看板の名前が1つだけの店にとって、「名前ごとに別に登録」が勝手に入った会社名を防ぐことになるのかがつながらない。「知ってから申し込めばいい」も、申し込むときに具体的に何をすればいいのか（看板の名前で登録できるのか）を言っていない。
- 結局、お客さんに見えるのが看板の名前になるのかどうかも、分からないまま。→【直す】1。

### 【直す】
1. シーン7「だったら、つまずく所を先に知って、準備する。…会社の名前と看板の名前が違う店は、そこを知ってから申し込めばいい。」（指摘4の続き。直しの後も残っている）
   - 何を準備すれば看板の名前で出られるのかが無いので、越え方に聞こえない。
   - 直し案の方向: 「申し込むときに、看板の名前で登録する（名前ごとに分ける）」のように、やることを1つ具体的に言う。資料で解決が確かめられないなら、「直せるかはまだ分からない。だから申し込む前に、どの名前で出るかを確かめる」のように、解決していないことをはっきり言う。
2. シーン12「最初に言ったとおり、日本で始まるなら、ネットで注文を受けて売る店から。」（直しで新しく生じた可能性が高い）
   - 「始まるなら」は、日本ではまだ始まっていないように聞こえる。シーン5の「ネットで注文を受けて売っている店なら、…申し込める」と食い違う。
   - 直し案の方向: 「日本で今申し込めるのは、ネットで注文を受けて売る店。町の店はまだ」のように言い切る。
3. シーン9「名前まで同じ、ビジネスエージェント。」（前からあったか判断できない）
   - 直したシーンの中では、ChatGPTの仕組みを「ビジネスエージェント」と呼んだ所が無い（シーン5では「案内役のAI」）。そのため、「名前まで同じ」が何と同じなのか分からない。カタカナの初出の言葉でもある。
   - 直し案の方向: 「ChatGPTのほうも、グーグルのほうも、ビジネスエージェントという同じ名前」のように両方の名前を言う。名前が同じなことに大事な意味が無ければ、この部分を削る。

### 【できれば】
1. シーン11「申し込めるのは、店のサイトがあって、身分証や事業の登録の書類で、本人確認が通る事業者。」／シーン11の締め「サイトがあって条件を満たせば、広告なしで…入口ができた」（指摘1の残り）
   - ホームページだけの会社でも申し込めるように聞こえる。「ホームページがあっても、ネットで注文を受けていない店は、今は町の店の側」と一言あると、「うちはどっちか」が決まる。
2. シーン12 判定の問いの「AIの答えで見つけてもらう」の部分
   - 二人とも「登録が始まるか」だけを答えていて、見つけてもらえるかには触れていない。問いを「日本の店の実際の登録は、この1年で始まるか」に絞るか、判定の台詞で見つけてもらえるかにも一言触れる。
3. シーン7「この道具は9月からあって、広告を出す機能も入っているから。」
   - これが、低い星の理由が登録の仕組みだけとは言えない理由だ、とつながるまでに一拍かかる。「低い星には、広告の機能への不満も混ざっているかもしれない」のように言い切ると分かりやすい。
4. シーン12「登録しても上位は保証しない、と会社は書いてる。」
   - 直したシーン11の台詞には「上位は保証しない」が無く（カードにだけある）、まとめの場面で初めて耳に入る形になっている。直していない前のシーンで言っているなら問題ない（判断できない）。

### 判定と二人の言い負かされ感
- 大輔が「町の店は先走りだった」と認め、沙織が「小さな店は入口にも立てない、は読み違い」と認めていて、どちらか一方が言い負かされた感じは無い。判定の割れ方（もうすぐ来る／根拠待ち）と、沙織が札を変える条件も分かる。
- 大輔が自分の予想を「先走りだった」と認めた直後に、また「この1年で」と言うので一瞬「懲りていない」と聞こえるが、「ネットで売る店から」と対象を変えているので、ついていける。
