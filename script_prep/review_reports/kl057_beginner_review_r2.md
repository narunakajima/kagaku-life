# kl057 初見レビュー（2周目・全文）

## 1. シーンごとの要約

- **シーン1〜4（予告）:** 買い物の相談をAIにする人が増えて、ChatGPTの中に店が値段や返品の決まりを入れられるようになった。沙織は「結局、大きな店かお金を出した店が勧められるのでは」と疑う。何の話かは分かる。
- **シーン5:** 11月10日にOpenAIが、ChatGPTの中に店の公式ページを持てる仕組みを試しに始めた、という紹介。二人の予想（大輔は1年で日本の町の店も準備を始める、沙織は大きな会社かお金を出した店だけ）と、日本で今だれが何をできるかの整理。最後に今日の問いと、確かめる3つを示す。日本の条件のところは込み入っていて、半分くらいしか頭に残らなかった。
- **シーン6:** 1つ目の論点。店がChatGPTに情報を届ける手順（名乗り出る、本人確認、青いチェック、情報を入れる）。大輔が「町のパン屋や工務店の看板になる」と夢を語り、沙織が「町の店は今はアメリカだけ」「入れた情報がそのまま出るの？」と返す。
- **シーン7:** OpenAIが確かめてから載せること、Shopifyの道具の評判が悪いこと（星1が9割近く）、つまずきは準備で減らせること、登録した店は紹介された回数などを28日分見られること。1つ目のまとめ。
- **シーン8:** 2つ目の論点。店の案内役のAI（ビジネスエージェント）にお客さんが質問できる。2つの商品で迷ったときに便利で、ChatGPTのふだんの答えとは分けて表示される。
- **シーン9:** 壁は「買えない・予約できない」ことと、置けるのはアメリカのネットの店だけ。だから案内係として使う。売り込みを禁止する決まりがあること、グーグルも同じことを始めていること。
- **シーン10〜11:** 3つ目の論点。お金を出した店が勧められるか。登録しても上位は保証しない、広告は分けて表示、広告は答えに影響しないとOpenAIは言う（外からの確認は無い）。広告なしで申し込める、料金は不明。沙織が「入口は小さな店にも開いていた」と認める。
- **シーン12:** 答え合わせと判定。大輔は予想の先走りを認めたうえで「もうすぐ来る」、沙織は日本の店が登録まで進んだ例を確かめられていないので「根拠待ち」。その例が出たら札を変える、と言う。
- **シーン13:** 今月の一歩。ChatGPTに自分の町の店を聞いて、出てくるか、営業時間や値段が合っているかを確かめる。違っていたら自分の店のサイトを直す。

## 2. 詰まった所の一覧

1. **シーン5、30〜35行目とシーン12の150行目**（「店の公式のページは、ChatGPTが使える国で、本人確認が通れば申し込める」「町の店は違う…名乗り出られるのは、今はアメリカで、そこに載っている店だけ」「条件の上で申し込めるのは、サイトのあるネットの店のほう」「日本の店が実際に登録まで進めたかは、資料からは確かめられなかった」→ 締めの「まずアメリカの、サイトのある店から」）
   - 重要度: 【直す】
   - 何が分からないか: 「うちの会社は今申し込めるのか」が、この動画で私が一番知りたいことなのに、最後まではっきりしない。分からなかった点は3つ。(1) 「ネットの店」と「町の店」の線がどこにあるのか。サイトを持っている工務店や菓子屋はどっちなのか。(2) 日本でも条件の上では申し込める、と言った後に、締めでは「まずアメリカの、サイトのある店から」と言うので、日本でも申し込めるのか申し込めないのか、逆になったように聞こえる。(3) 条件が4種類（店のページ／町の店／案内役のAI／日本での実例）も一度に出てきて、耳だけでは追えない。
   - 直し案（5章の整理）: 「日本の店で言うと、こうなる。ホームページのある店なら、会社や店の種類を問わず、店のページに申し込める、と書いてある。ただ、地図のように町の店がもう載っている仕組みのほうは、今はアメリカだけ。それと、店の案内役のAIも、今はアメリカだけ。」
   - 直し案（150行目）: 「今日覚えて帰ってほしいのは、店の看板が、通りや検索に加えて、AIの答えの中にも出る時代が始まったこと。ホームページのある店なら、日本からも申し込みの入口はある。店が自分で正しい情報を入れて、紹介された回数を見られる。」

2. **シーン5、32行目**「名乗り出られるのは、今はアメリカで、そこに載っている店だけ。」
   - 重要度: 【直す】
   - 何が分からないか: 「名乗り出る」が何をすることなのかは、シーン6まで説明されない。ここでは、何のために名乗り出るのか分からなかった。「ChatGPTの中に町の店の情報がもう店ごとに載っている」というのも初めて聞くので、ぴんとこない（地図アプリのようなものか？）。
   - 直し案: 「町の店は違う。ChatGPTには、地図のように、町の店や飲食店の情報がもう載っている。その店の持ち主が、うちの店です、と名乗り出て中身を直せるのは、今はアメリカの店だけ。」

3. **シーン7、70〜73行目**「紹介された回数って、店の名前が出ただけでも、1回になるの？」「ならない。…名前がちらっと出ただけでは数えない」
   - 重要度: 【直す】
   - 何が分からないか: 「紹介された回数」と聞くと、名前が出た回数だと思う。それを「数えない」と言われて、何を「紹介」と呼んでいるのか分からなくなった。店からすると、名前が出ること自体が大事なのに、それが数に入らないなら、何が分かるのかがかえって見えにくい。しかも「ネットの店なら」と断っているので、町の店はどう数えるのか、という疑問も残る。
   - 直し案: 「ならない。ネットの店の場合、数えるのは、AIが答えを作るときに、店のサイトの中身を参考にした回数。つまり、店の情報がちゃんと答えに使われた回数だ。」（町の店のことに触れないなら、「ネットの店なら」の断りを外すか、「町の店の数え方は今回は省く」と一言入れる）

4. **シーン7、58〜60行目**「Shopify（ショッピファイ）…そこに、OpenAIが作った、ChatGPTとつなぐ道具があるの。その評判は、9割近くが一番低い星」「この道具は9月からあるから」
   - 重要度: 【直す】
   - 何が分からないか: この道具が何をするものか分からない。だから、今回の店のページとどう関係していて、評判の悪さが今回の話にどれくらい効くのかが判断できない。「9月からある」と「11月の声は登録がうまくいかない」がつながるのは、この道具が今回の登録にも使われているからなのか？
   - 直し案: 「Shopifyで店を開いている人が、自分の商品をChatGPTに載せるための道具があるの。今回の店の登録も、この道具からできるようになった。その評判は、9割近くが一番低い星。」（関係が違うなら、関係をそのまま一言で言う）

5. **シーン6、50行目**「この先は、ネットの店だけじゃない。町のパン屋や工務店でも、ここが看板になる。」
   - 重要度: 【できれば】
   - 何が分からないか: シーン5で「町の店は今はアメリカだけ」と聞いた直後なので、大輔が話を聞いていなかったように聞こえる。「この先」がいつのことかも分からない。
   - 直し案: 「今はアメリカの町の店からだけど、いずれは日本の町のパン屋や工務店でも、ここが看板になると僕は思う。」

6. **シーン5、19行目**「ChatGPTの中に、お店が自分の窓口になる、公式のページを持てる。」
   - 重要度: 【できれば】
   - 何が分からないか: ChatGPTは質問に答えてくれる画面だと思っているので、「その中のページ」の見た目が想像できない。
   - 直し案: 「ChatGPTの答えに店の名前が出たら、そこから開ける、店ごとの公式のページを持てる。」

7. **シーン6、46行目**「店のサイトの設定に、決まった文字を書き込むか。」
   - 重要度: 【できれば】
   - 何が分からないか: 「サイトの設定」が何のことか分からない。サイトは業者に作ってもらったので、自分ではできなさそうだと感じて、気持ちが引いた。
   - 直し案: 「店の電話やメールに届く確認の番号を入れる。ホームページを使う方法もあって、そっちはサイトを作った業者に頼めばいい。」

8. **シーン6、43行目**「発表は、そこを新しい方法だと言ってる。」
   - 重要度: 【できれば】
   - 何が分からないか: 「そこ」が何を指すのかがあいまい。直前の「入口は無かった」を指しているので、「無かったことが新しい」と聞こえる。
   - 直し案: 「店が直接情報を届けられるようにしたのが、今回の新しいところだ、と発表は言ってる。」

9. **シーン13、158行目**「次はどんな研究が、誰かの幸せな未来を運んでくるのか。」
   - 重要度: 【できれば】
   - 何が分からないか: 今回は研究ではなく会社のサービスの話だったので、「研究」と言われて少し引っかかった（決まり文句なのだろうとは思う）。
   - 直し案: 決まり文句なら、そのままでもよい。

## 3. 総合評価

**(a) この動画が結局言いたいこと**
ChatGPTの中に、店が自分で正しい情報を入れて、AIに紹介された回数を確かめられる入口ができた。今はアメリカ中心で、店のAIは説明までしかできず、お金を出せば上に出る仕組みかどうかは会社の説明しかない。それでも、ホームページのある小さな店にも入口は開いているので、まずは自分の店がAIにどう紹介されているかを確かめるところから始めよう、という話。

**(b) 二人の判定に納得できたか**
- 大輔「もうすぐ来る」: だいたい納得。ただ、「日本でも申し込める」と「まずアメリカから」が両方出てくるので、何を根拠に「この1年」と言っているのかが少しぼやけた（詰まり1）。
- 沙織「根拠待ち」: 納得できた。日本の店が登録まで進んだ例がまだ無い、その例が出たら札を変える、と条件がはっきりしている。言い負かされた感じもなく、自分の読み違いを自分で認めているのが良かった。

**(c) 一番つらかった所トップ3**
1. シーン5の日本の条件の整理（30〜35行目）。条件が4つ重なって、自分の会社が当てはまるのか分からないまま進んだ（詰まり1・2）
2. シーン7の「紹介された回数」の数え方（70〜73行目）。かえって分からなくなった（詰まり3）
3. シーン7のShopifyの道具。何の道具か分からず、星1が9割近くという話の重さが測れない（詰まり4）

**(d) 冗長だった所・削ってもよい所**
- シーン5の33行目の画面と34〜35行目、シーン12の138〜139行目は、同じ「だれが何をできるか」の整理を2回している。シーン12は「店のページなら日本でも申し込める」の1文だけで足りる。
- シーン9のグーグルの段（102〜105行目）は面白いが、なくても話は通じる。残すなら短くてよい。

**(e) 前向きな気持ちになったか**
なった。シーン13の「ChatGPTに自分の町の店を聞いてみる」は今日すぐできるので、会社の名前で試してみたくなった。気持ちが少ししぼんだのは、シーン5の「町の店は今はアメリカだけ」と、シーン6の「サイトの設定に文字を書き込む」の所。うちのような会社には関係ないのか、自分ではできないのか、と感じた。シーン11の終わりで沙織が「小さな店にも開いていた」と言ったところで持ち直した。
