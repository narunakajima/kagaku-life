# kl057 初見レビュー（3周目・全文）

## 1. シーンごとの要約

- **シーン1〜4（予告）:** ChatGPTの中に店が値段や返品の決まりを入れられるようになった。沙織は「結局、大きな会社かお金を出した店が勧められるのでは」と疑っている。何の話かは分かる。
- **シーン5:** 11月10日にOpenAIが、店がChatGPTの中に公式のページを持てる仕組みを試しに始めた。二人の予想（大輔: 1年で日本の町の店も準備を始める／沙織: 勧められるのは大きな会社かお金を出した店）を出す。日本でどこまで使えるか（ネットの店は申し込める、町の店と店のAIはアメリカだけ）を言って、今日の問いと確かめる3点を出す。
- **シーン6:** 1つ目「AIは店のことを正しく話せるか」。店が名乗り出て、本人確認を通ると青いチェックが付き、値段などを入れられる、という登録の流れ。
- **シーン7:** 店が入れた情報はOpenAIが確かめてから載せる。Shopifyのアプリは星1が9割近くで、会社の名前が勝手に入った、という声がある。準備で減らせる。登録した店は、28日分の「サイトが参考にされた回数」などを見られる。
- **シーン8:** 2つ目「店のAIは役に立つか」。店の案内役のAI（ビジネスエージェント）に、商品の違いなどを聞ける。会話は分けて表示される。人の少ない小さなネットの店に効く。
- **シーン9:** 店のAIでは買えない。置けるのも今はアメリカだけ。案内係として使えばいい。売り込みを禁止する決まりがある。グーグルも同じことを始めている。
- **シーン10:** 3つ目「お金を出した店が勧められるか」。登録しても上位に出るとは限らない。広告はあるが、広告と書かれて答えとは分けて出る。
- **シーン11:** 広告は答えに影響しない、というのは会社の説明だけ。広告なしで申し込める。料金は分からない。沙織は「入口は小さな店にも開いていた」と認めるが、勧めてもらえるかはまだ分からないと言う。
- **シーン12:** 大輔は「町の店も」は先走りだったと認める。答え合わせのまとめと判定。大輔「もうすぐ来る」、沙織「根拠待ち」（日本の店が登録まで進んだ例が出たら変える）。
- **シーン13:** 今月の一歩として、ChatGPTに自分の町の店を聞いて、営業時間や値段が合っているかを確かめる。違っていたら店のサイトを直す。

## 2. 詰まった所の一覧

※改善アクション KL2611-03 の印について: 今回は前の周の指摘を渡されていないため、「見落とし」か「直しで新しく生じた」かは確かめられない。印は、言い回しから推し量ったもの（推定）として付ける。

1. **シーン5・12ほか「ネットの店」「町の店」の区別**
   - 引用: 「ネットで物やサービスを売る店なら、要るのは2つ。店のサイト……」「店を構えている、町のお店は？」「町の店と、店の案内役のAIは、今はアメリカだけ。」／判定の問い「日本の、サイトのある店が……」
   - 重要度: 【直す】（印: 推定 前の周からあった＝見落とし）
   - 何が分からないか: 私の会社は店を構えて売っていて、ホームページもある。これは「ネットの店」なのか「町の店」なのかが分からない。判定の問いは「サイトのある店」と言っているので、自分も入るように聞こえる。でもシーン12では「町の店の登録はアメリカだけ」と言う。いちばん知りたい「うちは申し込めるのか」が、耳で聞くと決まらない。
   - 直し案: シーン5の大輔「ここで言うネットの店は、ネットで注文を受けて売る店のこと。店を構えて、来たお客さんに売る店は、ホームページがあっても町の店の扱いで、こっちは今はアメリカだけ。」（実際の線引きが資料で違うなら、資料に合わせて一言で言う）

2. **シーン11「名前が出たかどうかは、1つ目で見た、28日分の数で、店ごとに確かめられる。」**
   - 重要度: 【直す】（印: 推定 直しで新しく生じた）
   - 何が分からないか: シーン7では「店の名前が答えにちらっと出ただけなら？」「それは数えない」と言っていた。ここで「名前が出たかどうかは数で確かめられる」と言われると、話が逆に聞こえる。まとめカードの「答えへの出方は、28日分の数で確かめる」も同じ。
   - 直し案: 大輔「答えに使われたかどうかは、1つ目で見た28日分の数で確かめられる。名前がちらっと出ただけでは数えないけど、サイトが答えの参考にされた回数と、押された回数は分かる。」

3. **シーン12 判定の問い「……見つけてもらう形は、この1年で来るか。」と大輔「この1年で、まずサイトのあるネットの店から、日本でも始まる」**
   - 重要度: 【直す】（印: 推定 前の周からあった＝見落とし）
   - 何が分からないか: 直前に「日本でも、サイトのあるネットの店なら申し込める」と言っている。もう申し込めるのに「この1年で来るか」「始まる」と言われると、何が来るのかが分からない。申し込めることと「来る」の違い（実際に日本の店が登録して、AIの答えに出始めること？）を言ってほしい。
   - 直し案: 沙織「申し込みの入口は、もう開いてる。札を付けるのは、その先。日本の店が実際に登録して、AIの答えで見つけてもらえるようになるのが、この1年で来るか。」

4. **シーン7「だったら、つまずく所を先に知って、準備する。……公式の書類と同じにして、とある。看板の名前が複数あるなら、名前ごとに別に登録する。」**
   - 重要度: 【直す】（印: 推定 前の周からあった＝見落とし）
   - 何が分からないか: 困りごとは「看板の店の名前ではなく、登記した会社の名前が勝手に入った」だった。それに対して「公式の書類と同じにして」と言われると、会社の名前で出るのが正しい、とも聞こえる。結局、お客さんに見えるのは看板の名前なのか会社の名前なのかが分からず、越え方になっていない気がする。
   - 直し案: 大輔「ヘルプの記事だと、本人確認には、書類どおりの会社の名前と住所を使う。看板の名前で出したいなら、看板の名前ごとに、別に登録する。最初から分けて申し込めば、会社の名前が勝手に入るつまずきは減らせる。」（資料で言える範囲に合わせる）

5. **シーン5「案内役のAIは、まずアメリカのネットの店から始まった。」**
   - 重要度: 【できれば】
   - 何が分からないか: アメリカだけの話が予想の中で突然出てきて、そのあと詳しく出てくる。予想を聞く前に、「店のページ」と「案内役のAI」の2つの機能があって、使える国が違う、という整理が頭に入らない。機能が2つ、店の種類が2つで、組み合わせを耳で追うのがつらい。
   - 直し案: 予想の前に大輔「今回の仕組みは2つ。店のページと、店の案内役のAI。どっちも、まずアメリカから始まった。」と一度だけ言っておく。

6. **シーン5「日本を外すとは書いてない。」とシーン12「申し込める、と書いてある」**
   - 重要度: 【できれば】
   - 何が分からないか: シーン5は「外すとは書いてない」と弱く言い、シーン12は「申し込める、と書いてある」と強く言う。日本で申し込めるとはっきり書いてあるのか、書いていないから多分大丈夫なのか、どちらなのかが揺れる。
   - 直し案: どちらかに統一する。例 シーン5「ChatGPTが使える国なら申し込める、と書いてある。日本も入る。」

7. **シーン6「サイトを使う方法もあって、そっちはサイトを作った業者に頼めばいい。」**
   - 重要度: 【できれば】
   - 何が分からないか: サイトを使って何をするのかが分からない。業者に何を頼むのか見当がつかない。
   - 直し案: 大輔「店のサイトに、決められた印を入れて確かめる方法もある。そっちは、サイトを作った業者に頼めばいい。」（中身は資料に合わせる）

8. **シーン7「この道具は9月からあって、広告を出す機能も入っているから。」**
   - 重要度: 【できれば】
   - 何が分からないか: 「だから低い星が全部登録のせいとは言えない」という理屈が、一度聞いただけではつながらない。
   - 直し案: 沙織「この道具は9月からあって、広告の機能も入ってる。低い星は、そっちへの不満も混ざってるの。」

9. **シーン7「登録の番号」**
   - 重要度: 【できれば】
   - 何が分からないか: 何の番号なのか（会社の登録の番号？ 電話の確認の番号？）。シーン6の「確認の番号」と混ざる。
   - 直し案: 「会社の名前や住所、法人の番号のような登録の番号を」

10. **シーン11 沙織「そこは私の読み違い。」**
    - 重要度: 【できれば】
    - 何が分からないか: 沙織の予想は「勧められるのは大きな会社かお金を出した店」だった。分かったのは「申し込める」ことで、勧められるかではない。認める範囲がずれているので、沙織が予想の芯ではない所で負けを認めたように聞こえる（すぐ「勧めてもらえるかはまだ分からない」と言うので、一方的に負けた感じまではしない）。
    - 直し案: 沙織「小さな店は入口にも立てない、と思っていた。そこは読み違い。でも、勧めてもらえるかは、外からはまだ分からない。私の予想の残り半分は、まだ決着してないわ。」

## 3. 総合評価

**(a) 言いたいこと（3文）**
ChatGPTの中に、店が自分の正しい情報を入れて、自分の窓口のページを持てる仕組みが始まった。今は買い物まではできず、町の店と店のAIはアメリカだけだが、サイトのあるネットの店なら日本でも広告なしで申し込め、AIに何回参考にされたかを数字で見られる。まずは自分の店がChatGPTにどう紹介されているかを確かめて、サイトの情報を直しておこう。

**(b) 判定に納得できたか**
- 沙織「根拠待ち」: 納得できた。日本の店が登録まで進んだ例が出たら変える、と条件がはっきりしている。
- 大輔「もうすぐ来る」: 半分だけ。もう申し込めると言った後なので、「この1年で来る」の「来る」が何を指すのかが分からない（詰まり3）。そのうえ、うちの会社が対象の「サイトのある店」に入るのかも決まらない（詰まり1）。

**(c) 一番つらかった所トップ3**
1. ネットの店と町の店の区別。うちが対象に入るのかが分からない（詰まり1）
2. 28日分の数で「名前が出たか」が分かるのか分からないのか、前の話と食い違う（詰まり2）
3. 「もう申し込める」のに「この1年で来るか」と問う判定（詰まり3）

**(d) 冗長・削ってよい所**
- シーン5とシーン12で、日本の店の扱い（ネットの店は申し込める、町の店はアメリカだけ）のカードと説明が2回出る。シーン12の2回目は「最初に言ったとおり」の一言で足りる。
- シーン10の冒頭で沙織が予告と同じ予想をもう一度言う所は、見出しと重なっている。
- シーン9のグーグルの話は面白いが、3つ目の論点に入る前で少し寄り道に感じる。

**(e) 前向きになったか**
なった。シーン13の「ChatGPTに自分の町の店を聞いてみる」は、今日すぐできるので試してみたい。気持ちが少ししぼんだのはシーン12で、「町の店はアメリカだけ」と「サイトのある店はこの1年で」が並んで、自分の会社が今申し込めるのかどうかが分からなくなった所。
