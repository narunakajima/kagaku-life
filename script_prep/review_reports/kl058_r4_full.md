# kl058 初見レビュー r4（全文）

## 1. シーンごとの要約

- **シーン1〜4（冒頭の予告）:** ハンドルの無い車を個人が注文できるようになったが、月々の契約が無いと動かない、という話。「車は月々払わないと動かない物になるのか」という問いが、短く伝わる。
- **シーン5:** テスラのサイバーキャブ（ハンドル・ペダルの無い2人乗り）が個人向けに売り出された。配車サービスではもう客を乗せて走っている。注文画面に「契約が無いと動かせない」とある、と問いを立てる。前回（福岡空港の無人貨物車）の続きなので、同じ3つの物差しと値段で測ると説明し、二人が予想を言う（大輔は1年で誰でも買える、沙織は3年）。
- **シーン6:** 本当に自分の車として買えるのか。招待された人だけ、値段は約480万円、予約金は約16万円で返金なし、12月にオースティンで受け取り。大輔は、運転をやめた親が自分で出かけられる使い道を出す。
- **シーン7:** アプリでできるのは「様子を見る・乗車を管理する」まで。免許が要るか、招待の外にいつ売るかは書いていない。代わりに、配車サービスで同じ車種に乗ってみることはできる（モデルYが来ることもある）。
- **シーン8:** 月約4万8000円の自動運転の契約と整備が、車を動かす条件。ハンドルが無いので、契約が切れたら自分で運転する逃げ道が無い。走れるのは「対応する区域」だけで、それがどこかは書いていない。
- **シーン9:** 配車サービスはテキサスとフロリダの8都市の限られた区域で走っていて、24時間営業になり、マイアミで範囲も広げた。持つか呼ぶかは、呼ぶ料金が分からないのでまだ計算できない。沙織は「区域の中で使うなら3年も待たない」と見立てを変える。
- **シーン10:** 日本では個人に売る話は無い。GO・日本交通・ウェイモが、2027年中に東京で無人タクシー100台規模を目指すと発表した。今は乗務員が乗った状態で試している。
- **シーン11:** 始める時期は許可が取れてから決める、2027年は目標。沙織の願い（出張先で使いたい）と、日本は「まず呼ぶ形、持つのはその先」という大輔の見通し。
- **シーン12:** 予想の答え合わせ、3つの物差しでの記録、最初の問いへの答え（注文画面どおりなら「はい」）。そのうえで札は「招待されていない人も1年で買って使えるか」に付ける。大輔「もうすぐ来る」、沙織「根拠待ち」。日本には札を付けず、札を付けられるようになる目印を2つ挙げる。
- **シーン13:** 今月の一歩として、自分の車に毎月いくらかかっているかを書き出して、この車の値段と並べておく。締め。

## 2. 詰まった所の一覧

【致命的】0件／【直す】1件／【できれば】5件

1. **シーン12 大輔「札は4つ。実現に近い順に、もうすぐ来る、3年はかかる、根拠待ち、まだ眉唾。」と、沙織「私は、根拠待ち。……遅れると見てるわけじゃない」「区域の中で使う話は……もっと早い」**
   - 重要度: 【直す】
   - 何が分からないか: 直前に「実現に近い順」で並べたので、耳では「根拠待ちは3年より遠い札」と覚える。そこへ沙織が3年から根拠待ちに変わったので、「もっと遅いと見るようになったのか」と受け取ってしまう。本人は「遅れるわけじゃない」「もっと早い」と言うので、矛盾して聞こえ、沙織の判定に納得しきれない。根拠待ちが「時期の見立て」ではなく「時期を言える資料がまだ無い」という意味の札だと、台詞のどこにも出てこない。
   - 直し案（大輔）: 「札は4つ。もうすぐ来る、と、3年はかかる、は時期の札。根拠待ちは、資料がまだ無くて時期を言えない、という札。まだ眉唾は、資料と合わない、という札。」
   - 直し案（沙織の行に加える例）: 「私は、根拠待ち。遅いという意味じゃなくて、時期を言える資料がまだ無い、という札。」
   - 印（KL2611-03）: 判別できない（この依頼では前の周の指摘を受け取っていないため）

2. **シーン6 大輔「テスラは、運転していた時間を、見る、働く、休む時間にできる、と書いてる。」**
   - 重要度: 【できれば】
   - 「見る」が何を見るのか分からない（景色？画面？）。
   - 直し案: 「運転していた時間を、画面で動画を見たり、仕事をしたり、休んだりする時間にできる、と書いてる。」

3. **シーン7 大輔「完全自動運転。アプリで車の様子を見て、乗車を管理する。」**
   - 重要度: 【できれば】
   - 「乗車を管理する」で何ができるのか想像できない（行き先を決める？誰が乗るかを決める？）。次の沙織の「そこまでしか書いてない」につなげる行なので、中身がぼんやりしていること自体は分かるが、言葉が硬い。
   - 直し案: 「アプリで、車の様子を見たり、乗るときの手配をしたりできる。書いてあるのは、それだけ。」

4. **シーン6 大輔「本体の見込みの値段が、およそ3万ドル（29,990ドル）。」**
   - 重要度: 【できれば】
   - かっこの中まで読み上げると、同じ数字を2回聞くことになり、耳では細かすぎる。
   - 直し案: 「本体の見込みの値段が、およそ3万ドル。税は別。」（細かい数字は画面だけにする）

5. **シーン12 沙織「それと値段。本体がおよそ480万円。それに、月々の契約がおよそ4万8000円。どちらも税は別。」（記録の場面、145〜150行）**
   - 重要度: 【できれば】
   - 値段を聞くのが3回目で、記録の場面が長く感じる。結論の前で少し気持ちがだれる。
   - 直し案: 「値段は、さっきのとおり。本体と、月々の契約。」

6. **シーン13 大輔「次はどんな研究が、誰かの幸せな未来を運んでくるのか。」**
   - 重要度: 【できれば】
   - 今回は研究ではなく会社の売り出しの話だったので、「研究」が少し浮く。決まった締めの文なら気にならない程度。
   - 直し案: そのままでもよい。変えられるなら「次はどんな発表が、……」。

問題が無かった観点: 冒頭の予告は分かる。英字の名前（サイバーキャブ、モデルY、ウェイモ、GO）にはすべて説明がある。「走れる区域」は呼び名を決めてから使っている。番号付きの並びは物差しの3つだけで、ぶつかっていない。二人とも一度ずつ譲っていて（大輔は「言い過ぎだった」、沙織は「見立てを変える」）、片方が言い負かされているようには聞こえない。

## 3. 総合評価

**(a) 言いたいこと（3文）:**
テスラが、ハンドルの無い車を招待した人に売り始めたが、月々の契約が無いと動かないので、車は「買えば自分の物」から「払い続けて動かす物」に変わりつつある。アメリカでは配車サービスで同じ車がもう客を乗せていて、招待された人が決まった区域の中で使う所まで来ている。日本はまず東京の無人タクシー（2027年が目標）からで、個人で持つのはその先になる。

**(b) 判定に納得できたか:**
- 大輔「もうすぐ来る」: 納得できた。同じ車がもう走っていて区域も広げている、招待のメールが「最初は数が限られる」という書き方、という理由が分かりやすい。
- 沙織「根拠待ち」: 理由（招待の外にいつ売るかがどこにも書いていない、招待なしで買えると発表されたら札を変える）は分かった。ただ、直前の「実現に近い順」の並びのせいで、「3年より遠くなったのに、もっと早いと言っている」と一瞬混乱した（項目1）。

**(c) 一番つらかった所トップ3:**
1. シーン12の沙織の札の説明と「実現に近い順」の食い違い（項目1）
2. シーン12の記録の場面が長く、値段の繰り返しで結論が遠い（項目5）
3. シーン7「乗車を管理する」が具体的に何なのか見えない（項目3）

**(d) 冗長な所:** シーン12で値段を3回目に読み上げる所。シーン6のかっこの中の細かい数字。札4つの読み上げはシーン5で一度説明しているので短くできる（ただし項目1の直しを入れるなら、ここで札の意味を言う価値はある）。

**(e) 前向きな気持ちになったか:**
なった。運転をやめた親が自分で出かけられる（シーン6）、出張先の夜の駅から宿まで（シーン11）は、自分の年代にはよく分かる。「今月の一歩」で社用車に毎月いくらかかっているかを書き出すのは、すぐできるので、やってみたくなった。気持ちが少ししぼんだのはシーン8〜9で、「どこを走れるか」「呼ぶといくらか」が書いていない、と続く所だけ。そのあと沙織が見立てを変えたので持ち直した。
