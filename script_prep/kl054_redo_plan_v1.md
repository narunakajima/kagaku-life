## 0. 前回の何を捨てるか

前回は「社員1人の会社（Mithril Medicine）が、AIで外注11か所を回した」＝**事務・段取りの話**を主題にした。
制作者の指摘どおり、これは今の生成AIで誰でもできる話で、幸せな未来が見えない。
**捨てるもの:** 「社員1人」を売りにする構え、メール・契約・書類の段取りを主題にすること、買収というニュースの形。
**残すもの:** Mithril は「論点3の中の1枚（少人数でも難病に挑める）」としてだけ使い、数字は『マウスで握力が約2倍』と『人での試験は早くて2028年後半』の2つに絞る。

## 1. 新しい企画の核

**視聴者側の問い（幸せな未来から立てる）:**
「食物アレルギーで一生エピペンを持ち歩く人、歩けないまま大人になる子ども、固形がんの患者に、
**新しい薬が『数年早く』届く未来**は、どこまで来たのか。薬を作る工程のどこが、いま実際に動き始めたのか。」

**見る人が得するもの（50〜60代の経営者・商売人向け）:**
1. 薬ができる道筋（①作る ②磨く ③届ける）のどこが詰まっていて、AIがどこを動かしたかが分かる。ニュースで「AI創薬」と聞いたとき、何の話かを自分で見分けられる。
2. 自分や家族が新薬にたどりつく時期の目安（人での試験は早くて2028年後半、という発表元の見通し）。
3. 経営の話として: 「人が決め、AIが広げる」分業で、**少人数のチームが扱える仕事の『枚数』が変わる**という、自分の会社に引き写せる形。

**驚きの1行:**
「食物アレルギーの薬を待っている人が、**今ある唯一の薬より多くのIgEを外した設計が、1か月でできていた**ことに驚く。」

**『創薬の世界がどう変わるか』を一言で:**
**「薬は『見つける』ものから『注文して設計する』ものに寄り、挑戦の“枚数”が人の数で決まらなくなる。」**
（前臨床＝人に入る前の段階に限った話。ここを台詞で言い切る。）

**二人の見立ての方向（判定の札は仮）:**
- 画面に出す札 `verdict`（二人が育てた使い方＝「難病・アレルギー・がんの薬づくりで、設計と確認の工程をAIに任せる」）:
  - 大輔 **もうすぐ来る**（もう6社の実験室で動き、試験管・細胞のデータが出ている。1年以内に同じやり方をする会社が増える）
  - 沙織 **根拠待ち**（人に入っていない。6社ぶんすべてが発表元と当事者の自己報告で、独立の検証はない。測定が1〜2回しかないものもある）
  - 割れていい回（CLAUDE.md「構成 v4」）。
- 記録用 `claim_verdict`（発表の言い方「AIが新薬の開発を速める」への見立て）: **根拠待ち**。
- **何が確かめられたら札が変わるか（台詞で必ず言う）:**
  - 「根拠待ち」が動く条件 … ①同じ設計がヒトでの試験に入る（発表元の見通しは早くて2028年後半）②当事者以外の研究機関が同じ手順で同じ結果を出す ③BigHat の「1〜2回しか測っていない値」が、確認試験で再現される
  - 「もうすぐ来る」が後退する条件 … 細胞・マウスで良かった設計が、動物の安全性試験で落ちる（過去に omalizumab の改良版 HAE1 が有害事象で中止になった例が、Divergence の報告に書かれている）

**題材の型（`topic_patterns.json`）:** `ai_capability`（AIにどこまで任せられるか）。
※ `body_health` ではない。驚きの中心はAIの能力と工程の変化で、健康の助言はしない。ジャンルは `medical`、`health` は **true**（ヒトの病気が主題）。直近5話は kl050 ai / kl051 humanoid / kl052 life_tech / kl053 humanoid なので、健康系は5話に1話。上限内。

## 3. 構成案（構成 v4「実現ラウンド」）

新しく説明が要る考え方は **5つ**: ①薬ができる3つの工程（作る／磨く／届ける） ②抗体＝体の中で特定の相手をつかむ道具 ③IgE＝アレルギーの引き金になる物質（免疫細胞にくっついている） ④前臨床＝人に入る前 ⑤外注の研究所（CRO）。
CAR-T・がんは「同じやり方がもう一つの病気でも動いた」として触れるだけにし、専門語は出さない。

### 流れとシーン別の目安尺（合計 約9分30秒）

| シーン | 種類 | 中身 | 目安 |
|---|---|---|---|
| S01 | teaser | 驚きの1行（「今ある唯一の薬より多く外した設計が、1か月でできていた」）＋ 判定の予告 | 15秒 |
| S02 | setup | お題と予想（**60秒以内**） | 55秒 |
| S03 | round1 | 作る — 食物アレルギーの薬の設計 | 155秒 |
| S04 | round2 | 磨く — 測り方そのものを疑う | 115秒 |
| S05 | round3 | 届ける — 人の判断が速さを決める／少人数で難病に挑む | 145秒 |
| S06 | verdict | 判定（**90秒以内**）＋ next_step | 85秒 |
| S07 | closing | 締めの固定文 | 30秒 |

※前回の S05（お題と予想142秒）・判定175秒を、ここで半分に削る。各論点は「夢・使い道 → 壁 → 越え方 → 残った手応え」の順を崩さない。

### S02 お題と予想（55秒）
- 大輔が「薬ができるまで」の工程を3つに分けて言う（作る／磨く／届ける）。画面は工程の図。
- お題: 「AIは、この3つのどこを、どこまで動かした？ 新しい薬が患者に数年早く届く未来は、どこまで来た？」
- 予想（tag `prediction`）: 大輔「3つ全部に少しずつ」／沙織「動いたのは書類だけだと思う」。
  → 沙織の予想が論点1で裏切られる形（tag `turn`）にする。前回のような「静かな前振り」にしない。

### 論点1「作る」（155秒）— 食物アレルギーの薬
- **夢・使い道:** エピペンを持ち歩き、2〜4週ごとの注射をやめられない生活。それを「くっついたIgEを外す」薬で変えられるなら。大輔「僕の身内にそばアレルギーの子がいたら、まずこれを待つ」
- **壁（沙織）:** 試したのは91個。くっついたIgEは数週間離れない相手。外す力は今の薬でも高濃度でしか出ない。何より、**細胞と試験管の話で、人にも動物にも入っていない**
- **越え方:** 約3万5千の設計案から絞り、試した91個のうち20個が外し、**3個は治療に使う濃度で今の薬より多く外した**。元になる既知の配列に頼っているという限界も、報告が自分で書いている。次は細胞→動物
- **手応え（tag `hope`）:** 従来の探し方なら数か月の仕事が、数週間で候補の部品に届いた（当事者の評価）。同じやり方が、がんの治療で使う細胞の部品を3分の1未満に作り直す仕事でも動いた
- **沙織の `skeptic_wish`:** 「本物なら、私が確かめたいのはここ。外す薬は、受容体をつなげてしまえば逆にアレルギー反応を起こす。そこを測った試験を見たい」
- **見せる画面:**
  - 夢: ピーナッツの写真 → エピペン（自己注射器）の写真
  - 壁: IgE が免疫細胞にくっついている図（NIH BioArt の mast cell 画像を使った自作の図）
  - 越え方: **グラフ（実数）** 35,000案 → 148個を選抜 → 91個を試験 → 20個が活性 → 3個が今の薬より上（棒／漏斗）
  - 手応え: 資料カード（Divergence 技術報告 Abstract の該当文、査読前と明記）

### 論点2「磨く」（115秒）— 測り方そのものを疑った
- **夢・使い道:** できた候補を「薬として持ちこたえる形」に磨く工程。回数が増やせれば、候補の質が上がる
- **壁（沙織）:** AIは分析を急ぎたがり、生データの曲線を「見ろ」と促されるまで見なかった（BigHat の研究者自身の記述）。さらに**主要な値は1〜2回の測定しかない**。1ウェルだけの値もある
- **越え方:** 促されたあと、AIは全部の曲線を読み、**名前のついた熱の指標が名前どおりのものを測っていない**ことを見つけ、指標と実験手順を変える案を出した。人の研究者なら数週間の作業を数日で。決めたのは人
- **手応え:** 「測り方を疑えるようになった」のが本当の変化。改良後、親より約9倍強くくっつき、融ける温度が8℃上がった
- **沙織の `turn`:** 「ここは認める。指標が間違っていると、モデルをいくら良くしても直らない。そこに気づいたのが一番大きい」
- **見せる画面:**
  - 壁: 7ラウンド×約1,010案の**グラフ（実数、ラウンドごとの件数）**
  - 越え方: 「測り方が違っていた」を1枚の図で（温度を上げたときの2本の曲線。名前と中身がずれている、を実数の軸なしの模式図＋「模式図」と明記）
  - 手応え: 資料カード（BigHat 技術報告 Abstract の該当文）＋ 数字カード「約9倍 / 8℃」
  - 壁の補足: 資料カード（"Lead values rest on one or two replicates"）

### 論点3「届ける」（145秒）— 速さを決めているのは人
- **夢・使い道:** 薬が患者に届くまでの待ち時間。そして、少人数のチームが難病に挑める形。大輔「社員が20人の町工場でも、挑戦の枚数が増える。これは会社の形の話」
- **壁（沙織）:**

## 4. 懸念

**誇張になりかねない点**
1. **「AIが新薬を作った」と聞こえること。** 設計の一部・測り方の見直し・書類の確認で、薬はまだ1つも人に入っていない。各論点で「人に入る前」と言う（発表元も "mostly preclinical" と書いている）。
2. **発表ページの数字の方が強い。** BigHat は発表ページ「10倍以上」に対し技術報告「約9倍／約6倍」。Generate は発表ページ「約70%短い・受容体10倍」に対し原著の要旨は「3分の1未満」で倍率なし。**台本は技術報告の数字を採る**。沙織が一言だけ「紹介文より報告の本文は控えめ」と触れる。
3. **時間短縮の数字の出どころ。** Enveda の「規制書類の下書きが4時間（手作業なら3か月）」は技術報告が時間を測っていないので使わない。「89%減」も採らず「約26時間→3時間弱（9.4分の1）」と言う。
4. **「2028年後半に治験」は発表元の見通し。** 予定であって約束ではない、と添える。3年を超える言い方はしない（2028年後半は約2年先なので範囲内）。

**独立した検証が無い点**
- 6社の成果はすべて当事者（＋Anthropic）の自己報告で、**査読前**。Divergence・Generate・Mithril・BigHat は preprint／技術報告。Enveda は自分で「探索的」と書いている。
- この回に「第三者の検証」は存在しない。**答え合わせ回の型（独立評価2つ以上）は使えない**ので、誠実さは「出した側が自分で書いた限界を読む」形で担保する（AIの誤りが4日以上気づかれなかった、1〜2回の測定しかない、正式な品質システムではない）。

**健康系として言ってはいけない点**
- 具体的な薬の名前を「効く・待てばよい」の文脈で言わない。omalizumab は「今ある唯一の承認薬」という事実の紹介にとどめ、用量・使い方は言わない（資料にあっても言わない）。
- 「この研究が自分の病気に使える」と受け取れる言い方をしない。判定の中で「研究の紹介で、おすすめではありません」と一度言う。
- 二人に医師を名乗らせない。沙織は臨床研究・統計の目で限界を読むだけ。
- 患者数・死亡の数字は、煽らず事実として1行ずつ。

**競合動画（YouTube 日本語、2026-11-08に確認）**
- 「AI創薬」全般は大きな需要あり: PIVOT 2本が3日前で8〜9万回、NewsPicks が2週間前で12万回。
