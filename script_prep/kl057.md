## 1. 論点ごとの「中学生に3文で説明すると」

**論点1「AIは、店のことを正しく話せる？」**
今まで ChatGPT は、店のことをネットの情報から集めて答えていて、店の側から情報を届ける入口は無かった。今回、店が「うちの店です」と名乗り出て、身分証や事業の登録の書類で本人確認が通ると、値段・在庫・返品や配送の決まりを自分で入れられ、青いチェックが付く。さらに、過去28日にAIの答えで何回紹介されたか、サイトが何回押されたか、どんな話題で名前が出たかを、店が見られる（一人ひとりの会話は見えない）。

**論点2「お客さんは、店のAIと話せる？」**
AIの答えに店が出たら、お客さんはその店のページを開いて、店が用意した案内役のAIに質問できる（会話は元の会話と分けて表示）。今できるのは商品と決まりの説明と店のサイトへの案内までで、買う・予約・注文の確認はできず、作れるのはアメリカのネットの店だけ。急かす・断られた後も売り込む・健康や身分証を聞く、などは決まりで禁止されていて、同じような案内役のAIはグーグルも1月に検索の中で始めている。

**論点3「お金を出した店が勧められる？」**
広告の枠はあって、店の案内役のAIを広告の行き先にもできるが、広告と示され、答えとは分けて出る。OpenAI は「登録しても上位表示や売上は保証しない」「広告は独立した答えに影響しない」と書き、広告を出す登録がなくても申し込める。ただし答えが本当に独立しているかは会社の言い分で、外からは測れないので、店は28日分の数で自分の紹介のされ方を確かめる。

## 3. 初めて説明が要る考え方（4つ）

1. 店の公式ページ（名乗り出る → 本人確認 → 青いチェック → 値段・在庫・決まりを入れる）
2. 紹介の回数（言及数・サイトのクリック・話題。28日分、会話は見えない、サイトが元になると1回）
3. 店の案内役のAI（Business Agent。説明と案内まで）
4. 広告の枠（スポンサー付き。広告と示し、答えと分けて表示）

5つ以内。Persona・商品フィード・TXT記録は言葉にせず「本人確認」「値段や在庫の一覧」で済ませる。

## 4. キーワード（初出で定義する）

- **店の公式のページ**: ChatGPT の中で、店が自分で情報を入れ、管理するページ（S05 行1・3）。タイトルの「店の窓口」と同じものだと S05 行1 で言う
- **案内役のAI**: 店が用意し、店が渡した情報で客の質問に答えるAI。発表での名前はビジネスエージェント（S05 行3、S08 行1）
- **名乗り出る**: ChatGPT に「地図アプリのように」もう入っている店の中から自分の店を探し、「うちの店です」と申し出ること（S06 行4 で初出と説明を同時に。S05 では使わない。初見r2 2）
- **青いチェック**: 本人確認が通った店に付く、確認済みの印（S06 行6）
- **サイトが参考にされた回数**（旧「紹介された回数」。初見r2 3で改名）: ネットの店で、AIが答えを作るときに店のサイトを参考にした回数。名前が出ただけでは数えない（S07 行12・15）
- **ヘルプの記事**: OpenAI の、使い方の説明のページ（S07 行1）
- **ショッピファイ**: ネットの店を作るサービスの大手。そこで店を開いている人向けにOpenAIが出した道具から、今回の店の登録や、商品の一覧をChatGPTに送ることができる（S07 行3。アプリのページ「Business Hubに自動同期」「ビジネスを登録」、ヘルプの確認方法・商品フィードで確認。初見r2 4）
