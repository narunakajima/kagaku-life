## A. Anthropic Economic Index（Claude の利用実態）

### A1. 「Cadences」（最新）
- URL: https://www.anthropic.com/research/economic-index-june-2026-report
- 発表: Anthropic Economics チーム（Massenkoff ほか）、2026-06-26。開いて確認（要約経由）
- 対象・期間: チャットと Cowork の会話を 2026-04-10〜06-10 に毎日抽出（プライバシー保護の計測基盤）。総会話数は書かれていない。Claude Code のセッションは自律度の比較に使用。アンケート（Anthropic Economic Index Survey、2026年4月開始）は利用データと結びつけた約9,700人、1人あたり最大20セッション、5セッション未満は除外
- 主要な数字:
  - 「93% of Claude conversations produced an artifact」（成果物ができた会話93%）。内訳は説明17%、文書・レポート15%、助言11%が上位
  - 自律度（1〜5）は Claude Code の方が高い（31種の成果物のうち26種）。平均差0.37点、差の約3分の2は「同じ仕事をより多く任せている」ため。例: ブログ記事で、チャット/Cowork の中央値は人とAIの往復13回、Claude Code の中央値は人の指示1回
  - 個人利用の会話は平日約35%、週末は約50%弱
  - アンケート（要約経由の記述）: 「close to 6 in 10」が今より来年の方が高いAI関与の区分を選び、「over a third」が来年はほとんど全ての仕事をAIがこなすと予想。自己申告の効果は速度86%、範囲82%、品質69%、コスト削減27%
- 本文に書かれていないこと（重要）: 「長時間の自走（エージェント的）セッションの割合」「指示型（directive）の全体割合」「人の確認・修正の割合」は報告されていない。原文は Claude のセッションが「increasingly consist of long-running agentic tasks」と述べるのみ（割合なし）。日本には言及なし
- 著者の限界: アンケートは代表性がなく、コンピュータ・数学系が約30%（米雇用の4%）、管理職23%、女性12%。学習や技能向上は自己評価で「do not rule out skill erosion」。分類は別の Claude が会話を読んで行い、区分は「moving target」

### A2. 「Learning curves」
- URL: https://www.anthropic.com/research/economic-index-march-2026-report
- 発表: 2026-03-24。開いて確認（要約経由）
- 対象・期間: 2026-02-05〜02-12、Claude.ai と1P API から各100万会話
- 主要な数字: Claude.ai の上位10タスクの占有率は24%→19%、API は28%→33%。Computer and Mathematical が Claude.ai の35%。個人用途35%→42%、宿題・授業19%→12%。「API workflows are far more likely to be directive, with less need for a human in the loop」。コーディングは Claude.ai から API へ移行中。営業アウトリーチ自動化・自動取引運用の占有率が2倍以上。本文に automation/directive の正確な割合は無い
- 著者の限界: 成功判定は Claude 自身の評価。生存者バイアス・コホート効果。2週間の単一窓。「not broadly representative of the US economy」

### A3. 「Economic primitives」
- URL: https://www.anthropic.com/research/anthropic-economic-index-january-2026-report
- 発表: 2026-01-15。開いて確認（要約経由、最後の605字は未読）
- 対象・期間: 2025-11-13〜11-20、Claude.ai（Free/Pro/Max）100万会話 + 1P API 100万件
- 主要な数字:
  - Claude.ai: 拡張（augmentation）52%、自動化（automation）45%。2025年1月は拡張56%・自動化41%、2025年8月は自動化が一時上回った
  - 指示型（directive、最小限のやり取りで完了）: Claude.ai 32%（8月は39%）、API 64%
  - 仕事用途: API 74%、Claude.ai 46%
  - タスク成功率: API 49%、Claude.ai 67%。複雑な仕事ほど成功率が下がる（API で5時間以上の仕事は約45%）
  - 上位10タスク: Claude.ai 24%、API 32%。最多は「ソフトウェアの誤り修正」（Claude.ai の6%、API は約10件に1件）
- 著者の限界: 「none of the measures should be taken as exact or definitive」。API は単発の記録で複数ターンを捉えられない。成功は利用者が選んだ仕事に偏る

### A4. 「Measuring AI agent autonomy in practice」（エージェント的利用と人の確認）★本論点に最も近い
- URL: https://www.anthropic.com/research/measuring-agent-autonomy
- 発表: Anthropic Societal Impacts チーム、2026-02-18。開いて確認（要約経由）
- 対象・期間: Claude Code 対話セッション約50万、公開 API のツール呼び出し998,481件（2025年末〜2026年初）
- 主要な数字:
  - 公開APIのツール呼び出しの「nearly 50%」がソフトウェア開発。他の分野は数%以下
  - ツール呼び出しの約80%は、権限制限や承認要求などの安全策が1つ以上ある
  - 約73%に人が関与しているように見える（著者は過大評価の可能性があり上限値と注記）
  - 取り消せない行動（顧客へのメール送信など）は約0.8%
  - Claude Code: 自動承認はセッション50回未満の利用者で約20%、約750回で40%超。人が割り込むターンは約5%（経験10回程度）〜約9%（経験者）
  - 人が割り込む理由の上位: 技術的文脈の不足・訂正32%、遅い・止まる・やり過ぎ17%
  - Claude が自分で止まる理由の上位: 選択肢の提示35%、診断情報の収集21%
  - ターン長の中央値は約45秒。長い方の99.9パーセンタイルは25分未満→45分超
  - 社内利用: 8月〜12月で最難関タスクの成功率が2倍、1セッションあたりの人の介入は5.4回→3.3回
- 著者の限界: Anthropic のモデルのみ。API データは単発の呼び出しでセッション全体ではなく、Claude Code は大半がソフトウェア開発。分類は Claude が行い人は中身を見られない。単一期間で、サンプリングが複数ステップの流れを過大に拾う。人による後段の確認は見えない。本番と評価・レッドチーム検証を区別しきれない
- 注: 「エージェント的な使い方の比率」や「人が確認・修正する割合」に最も近いが、対象はコード作業中心で、一般の生活者の手続き・事務の割合ではない

## B. OpenAI「How People Use ChatGPT」
- URL: https://www.nber.org/papers/w34255（PDF: https://cdn.openai.com/pdf/a253471f-8260-40c6-a2cc-aa93fe9f142e/economic-research-chatgpt-usage-paper.pdf、本文を端末で抽出して確認）
- 発表者: Chatterji, Cunningham, Deming, Hitzig, Ong, Shan, Wadman（OpenAI と Harvard ほか）。NBER Working Paper 34255、2025年9月（査読論文ではなくワーキングペーパー）。2026年の更新版は確認できず（未確認）
- 対象・期間: 消費者プラン（Free/Plus/Pro）のログイン利用者から無作為抽出した約110万の匿名化メッセージ（2024年5月〜2025年6月）。人は内容を見ず、LLM分類器で分類。成長データは2022年11月〜2025年9月。2025年7月時点で世界の成人の約10%が利用
- 主要な数字（原文）:
  - 「about 49% of messages are Asking, 40% are Doing, and 11% are Expressing」
  - 仕事関連メッセージでは Doing が約56%、Asking 35%、Expressing 9%。「nearly three-quarters of those are Writing tasks」
  - 「Nearly 80% of all ChatGPT usage falls into」Practical Guidance、Seeking Information、Writing の3つ（別の箇所では「about 77%」）
  - Writing は仕事で最多で、2025年6月に仕事関連メッセージの40%。Writing の約3分の2は利用者の文章の修正（編集・翻訳など）で、新規作成ではない
  - コンピュータ・プログラミングは全メッセージの4.2%（Claude の仕事関連会話では33%と対比して記載）
  - 2025年6月時点の分け方は Asking 51.6%、Doing 34.6%、Expressing 13.8%（別の分類器の推移図）
  - 仕事外のメッセージ比率は2024年6月の53%から増加（要約では70%超）
- 著者の限界・範囲: 消費者プランのみ（Business/Enterprise/Education は対象外）。プログラミングは API やコード編集支援・自律型プログラミングエージェント（Codex など）に移っている可能性があると書かれ、ChatGPT のメッセージ分析にはエージェント的な使い方が含まれない。「Doing」は「出力を作らせる」意味で、複数手順を自動で進める意味ではない
- 注: OpenAI の公式ブログ（openai.com）は取得が403で、原文は NBER 版 PDF で確認した

## 判断: 「人がAIに任せている仕事の内訳」を一般の人に3文で説明できるか
結論: 「いま主流は、調べる・相談する・文章を作る/直すで、手続きの丸ごと代行はまだ一部の開発者中心」という3文は、出典を明示すれば言える。ただし「エージェント的利用の全体比率」は言えない。

使える3文の材料:
1. 【ChatGPT、約110万メッセージ】質問（Asking）約49%、作業を頼む（Doing）約40%、気持ちの表明約11%。仕事の場面では頼む側が約56%で、その4分の3近くが文章作成。しかも文章作成の約3分の2は自分の文章の修正（OpenAI/NBER）
2. 【Claude】会話の93%で何らかの成果物（説明・文書・助言など）ができている。長時間自走する使い方は増えているが、その割合は公表されていない。自走の実測が出ているのはコード作業で、Claude Code では人の割り込みが5〜9%のターン、自動承認は慣れるほど20%→40%超、API のツール呼び出しの約半分がソフトウェア開発で、取り消せない行動は約0.8%（Anthropic）
3. 【日本、総務省アンケート】利用経験58.8%（20歳以上は52.2%）。目的は「情報の理解」が最多で、次が文書作成・校正・翻訳。ほぼ毎日使う人は約3割で、日常の手続きを任せる使い方を示す数字は白書ページに無い

注意点（台本で誠実に言うべきこと）:
- 数字はいずれも提供企業（Anthropic、OpenAI、Microsoft）自身の公開分析で、自社サービスの利用者に限る。ChatGPT の分析は消費者プランのみで、エージェント製品は含まない
- Anthropic の「automation」は「指示型・フィードバックループ」の会話の意味で、「手続きを丸ごと代行」ではない。言い換えるときに混ぜない
- Doing 約40%は「頼んで出力を得る」ことで、複数手順の自動実行とは別物
- 日本はアンケート（自己申告）のみ。ログ型の内訳は未確認
- 暮らしの手続き（役所、予約、支払い）をAIに任せる実態データは、今回の範囲で見つからなかった。この点は「まだデータが無い／少ない」と言うのが正確
