## 製品・承認
- 販売名「リハート」、クオリプス株式会社。一般的名称: ヒト（同種）iPS細胞由来心筋細胞シート
- 形状: iPS細胞から分化させた心筋細胞を1枚あたり3.3×10^7個のシートにし、ゼラチンのゲルに包埋
- 効能: 薬物治療や侵襲的治療を含む標準治療で効果不十分な虚血性心筋症による重症心不全の治療
- 審査結果: 「一定の有効性は期待でき、安全性は許容可能。ただし現時点では情報が限られており、製造販売承認後も継続して有効性を評価し確認することが適切」
- 承認区分: 条件及び期限付承認。期限 7年。承認条件=(1) 全症例対象の製造販売後調査 (2) 開胸手術と重症心不全に十分な経験のある医師が体制の整った医療機関で使う（適正使用指針・講習） (3) 作用機序を反映する生物学的特性の情報収集
- 用法: 左側開胸で心臓表面にシート3枚（計約1×10^8個）を移植。翌日から免疫抑制剤3剤（プレドニゾロン・タクロリムス・ミコフェノール酸モフェチル）を漸減しながら90日間

## 臨床試験 CVSC0005（2019年12月〜2024年3月、5施設、多施設共同・非盲検・非対照、目標8例）
- 対象: 20歳以上、慢性虚血性心疾患、NYHA Ⅲ〜Ⅳ、最大限の薬物療法でも心不全、標準治療後3か月以上、安静時LVEF 35%以下
- 審査側の位置づけ: 「探索的な位置付けとして、少数例を対象に非盲検非対照で実施された試験。結果に基づき有効性を評価することには限界がある」
- 一方で審査側は「一度壊死した心筋が自然に回復して心機能が改善することは期待できないため、その点を踏まえた有効性評価は可能」とも書く
- 主要評価: 移植後26週のLVEF（心エコー）が移植前より改善 → **8例中2例だけ**
  - 変化量（%ポイント、症例1〜8の順）: +3.5 / −5.1 / +15.0 / −9.1 / +5.6 / −3.3 / +0.3 / −11.4
  - 移植前→26週: 25.6→29.1, 20.5→15.4, 32.7→47.7, 32.3→23.2, 38.7→44.3, 36.3→33.0, 19.9→20.2, 37.9→26.5
- 総合評価（治験責任医師の評価を3人の専門家委員会が確認）: 26週で6例有効・2例無効、52週で8例全例有効
  - 審査側の指摘: 「一部の客観的評価項目に悪化があるにもかかわらず、症状改善から有効と判断することには限界があり、Responder の判定は慎重な判断が必要」
- NYHA: 移植前は全例Ⅲ度 → 26週でⅡ度6例・Ⅰ度2例 → 52週でⅡ度4例・Ⅰ度4例。審査側は「非盲検で心理的な影響も否定できない」
- Peak VO2（運動時の酸素の取り込み）が10%以上増えたのは52週で4例。審査側「臨床的に意義のある変化で、有効性を示唆する」。ただし心臓リハビリや患者の意欲の影響は否定できない
- SAS（活動度）: 1METs以上の増加は26週で5例、52週で4例。1METs以上減ったのは52週で1例
- BNP/NT-proBNP は上昇した例があり、審査側は「運動量が増えたことによる可能性、臨床的には軽微」と解釈
- 安全性（8例）: 有害事象7例（87.5%）。重篤な有害事象5例（62.5%）10件（胸部不快感、尿路感染、急性心不全、アミオダロン肺炎、心室血栓症、感染性腸炎、結腸癌、大腸穿孔、膝蓋骨骨折、心不全）。全て回復、本品との因果関係は否定。本品の副作用0。免疫抑制剤との因果関係が否定できない有害事象7例（白血球数増加3、高血糖3、腎機能障害2。中止後に回復）。死亡に至った有害事象0

## 機序・動物データ
- ラットでの試験で、心機能改善はパラクライン効果（移植細胞が出す物質が周りに働く）の可能性。審査側は「改善がパラクライン効果のみか、寄与する物質が何かは明らかでない」
- ヒトでの移植細胞の生着期間は不明（臨床の体内動態評価は未実施）。移植細胞はラットでも時間とともに減る

## 市販後（使用成績調査計画・案）
- 全例調査方式。対象=移植された全ての虚血性心筋症患者
- 目標症例数 **75例**（承認から5年間、または目標到達のいずれか早い日までに移植した例を有効性の解析に入れる。それ以降の例は安全性のみ）
- 比較: 無作為化は開胸手術を伴い倫理的に困難なので、**別に行う前向き臨床研究の「標準治療で効果不十分な患者」を外部対照**にする（傾向スコアでマッチング）
- 主要評価: 移植52週で Peak VO2 がベースラインから10%以上増加、かつ LVESVI（左心室の収縮末期の大きさ）が改善または維持した患者の割合。有意水準は両側10%
- 副次: 心不全入院、生存率、6分間歩行、NYHA、LVEF など。安全性: 腫瘍の発現、免疫抑制剤の副作用など
