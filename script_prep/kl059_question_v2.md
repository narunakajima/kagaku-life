## 3. 問いの案（下書き7つ → 外れた型で4つ落とし、3案）

起点（幸せな未来）: **買い物の「探す・比べる・レジまで進む」はAIがやり、人は最後に金額を見て「いいよ」と押すだけ。その暮らしは、日本でもう始まっている。**

### 案A（暮らし・答え合わせ）— 推奨
- **問い:** AIに買い物を頼む暮らしは、日本でもう始まっている。「最後のひと押し」まで任せきりにするには、あと何が足りない？
- **視聴者の想定:** 50〜60代。スマホで通販・チケットは買うが「AIに財布を触らせるのは怖い」人。店を持つ人には「客がAIで買いに来る」の入口にもなるが、主語は暮らす人
- **冒頭15秒のフック:**
  大輔「AIに頼んで、映画館のチケットと、通販のペット用品を買った。日本で。お金もちゃんと払えた。体験者が、実際にやってみたんだ」
  沙織「アメリカでは今月、ChatGPTの“AI用の財布”が始まったばかり。でも日本では、MetaのMuseで、もう払える。じゃあ、最後の“いいよ”まで任せきりにできる日は来る？」
- **驚きの1行:** AIの買い物代行はアメリカの話で、日本ではまだ先だと思っている人が、日本でももうAIが映画館のチケットまで払っていて、人がやるのは最後に金額を見て「いいよ」と押すことだけだと知って驚く
  （根拠: 支払いは体験者の体験、「最後に本人が承認」は Meta・Stripe の公式資料。「日本で誰でも必ず通る」とは言わない）
- **タイトル案（35字）:** AIが映画のチケットまで払った。日本でもう始まった「お任せ買い物」（11月時点）

- **題材の型:** `ai_capability`（AIにどこまで任せられるか）
- **論点の見込み（構成 v4）:**
  1. 「日本で、もう払えた」— 夢: 探して比べて払うまで任せる／体験者の2件（通販サイト＝店に保存した支払い、映画館＝Link）／壁: 公式の日本向け案内に「日本で Link 決済」の記述は無い・見た実演はみな決済の手前で止めている／越え方: 2つの払い方（店に預けた財布、AI用の使い捨て番号）があり、どちらも Muse は本物の番号を見ない（公式）／手応え: 体験者の体験では通った
  2. 「最後の“いいよ”は、なぜ残る？」— 沙織 skeptic_wish「本物なら、親の分の買い物も頼みたい」／壁: Muse は間違えることがある・エラーを直すのは利用者（ヘルプ）・サイトによってはAIの買い物を止める（OpenAI の手引き）／越え方: 金額を見て承認・記録が残る・止められる操作がある／手応え: アメリカは毎回の生体認証とカード会社の身代わり番号で、承認の形そのものを強くし始めた（ChatGPT ウォレット）

## 4. 推奨と理由

**推奨: 案A。**
- **面白さ（驚き）:** 「AIの買い物代行はアメリカの話」と思っている人に、「日本で、映画館のチケットまで払えた」と見せられる。日本語の解説動画は飽和しているが、見た範囲の実演はすべて決済の手前で止めていて、**実際に払ったところまで見せる動画が見当たらない**。当チャンネルが出す意味がはっきりある
- **自分ごと:** 50〜60代の「財布は自分で握る」感覚に直接触れる。答えが「最後のひと押しだけ自分」で、怖さを否定も煽りもしない（構成 v4 の「育てる」形）
- **見せられるか:** 承認画面（もらえれば）、チケット、2つの払い方の図。Shorts 向き強め
- **続き物:** kl048 の締め「支払いは最後まで自分で押す」の答え合わせになり、旧 kl059 の ChatGPT ウォレットの材料（毎回の生体認証・身代わり番号・事前承認の構想）は論点2・3で生かせる（作り直しの手戻りが少ない）
- **旬・注目度（入る条件）:** Muse は日本で11月も新機能・話題が続く（11/14〜11/18 の動画多数、NewsPicks 57万・PIVOT 25万再生）。ChatGPT ウォレットは11/13 発表
- **案B の「2つの財布」は案A の論点1に入れる。案C の「アメリカは日本で使えない」は案A のフックに入れた**

### 懸念（書き手・編集長へ）
- **体験者の体験と公式資料の食い違い:** Stripe は「米国の消費者」、Impress Watch も「米国では」と書く一方、体験者は日本で Link で払えた。台本では「公式の案内では、日本で Link が使えるとは書いていない。でも体験者が試したら通った」と並べる。「日本で誰でも使える」とは言わない。札も「体験者の体験では」を含めた見立てとして台詞で区別する
