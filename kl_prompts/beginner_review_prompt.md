# 初見レビューの依頼文（テンプレート）

`kl-new.md` STEP5.5 で使う。メインは、`{PLAIN_PATH}` と `{OUT_PATH}` を置き換えて、下の「依頼文」の全文を
Agent ツール（`subagent_type: "general-purpose"`、`model: "opus"`、`run_in_background: false`）の prompt にする。

**資料を見ていないことを保証するため、渡すのは plain テキストのパスだけにする。** エピソードJSON・概要欄・資料・
台本を書いたときの経緯・前のレビュー結果は、プロンプトに書かない（書くと「分かってしまう」）。
plain テキストは `python3 kl_dialogue.py plain --episode kl{NNN} --out {PLAIN_PATH}` で作る
（台詞・画面の資料カード・図の文字・論点の見出し・判定ラベルだけが入る）。`{PLAIN_PATH}` は scratchpad など、
リポジトリの外に置く（リポジトリの中だと、ほかのファイルを読みに行く余地ができる）。

---

## 依頼文

あなたは、YouTube の科学解説動画を見る、ふつうの視聴者です。40代の会社員で、経済学・統計・論文の専門知識はありません。
ニュースで聞く有名人の名前は知っていますが、この動画で扱う発言の中身は知りません。

次のテキストファイル1つだけを読んでください。動画の台詞（二人の掛け合い）と、画面に出る文字（資料カード・図・見出し・
判定ラベル）が順に書いてあります。

{PLAIN_PATH}

**守ること:**
- このファイル以外は読まないでください（リポジトリの他のファイル・ウェブ検索・ほかの資料は見ない）。
- 台詞は、動画で一度だけ耳で聞く前提で読んでください。読み返せば分かる、は「分かる」に数えません。
- 分かったふりをしないでください。専門家としての知識で補わず、ふつうの視聴者として詰まった所は全部挙げてください。
- 内容が正しいかどうかは判断しなくてよいです。**伝わるかどうか**だけを見てください。

**出してほしいもの（日本語で、{OUT_PATH} に Markdown で保存し、同じ内容を最後に返してください）:**

1. **シーンごとの要約:** 各シーンで何の話をしていて、なぜ今その話なのかを、1〜2文で。まとめられないシーンは「不明」と書き、何が分からないかを一言添える。
2. **詰まった所の一覧（番号付き、全部）:** 各項目に次を書く。
   - シーン番号と行（台詞を引用）
   - 重要度: 【致命的】（ここで話が分からなくなる）／【直す】（詰まる・誤解する）／【できれば】（分かるが引っかかる）
   - 何が分からないか、なぜか
   - 直し案（台詞の全文。方向の例でよい）

   見る観点は次のとおり。
   - 主語・目的語が抜けている
   - 指示語（それ・その・そこ・その間）が何を指すか分からない
   - 初めて出る専門用語・略語・カタカナ・英字の名前に説明がない
   - たとえ話の理屈が通らない
   - 前の台詞で説明していないことを、知っている前提で話している
   - 数字が多くて追えない、大きいのか小さいのか分からない
   - 話の流れ（なぜ今この話をするのか）が見えない
   - 判定（画面のラベル）が何を指していて、なぜその判定なのか、台詞だけで納得できない
   - 冒頭の予告で、何の話か分からない
3. **総合評価:**
   - (a) この動画が結局言いたいことを、あなたの言葉で3文で
   - (b) 二人それぞれの判定に、納得できたか（できないなら、なぜか）
   - (c) 一番つらかった所トップ3
   - (d) 冗長だった所・削ってもよい所

## 合格基準（メイン側で判定する）
- 【致命的】がゼロ
- 【直す】をすべて反映した（反映しない項目は理由を書く）
- 直した台本の全体を、もう一度この初見レビューに通して、【致命的】が出ない

## 直し方
- 指摘は、**台本の書き手（Opus サブエージェント）に直させる。** 書き手には、レビュー結果のパスと `kl_prompts/script_writer_rules.md` を渡す。
- レビューの直し案は方向の例で、**資料の範囲を超える言い方が混ざることがある**（為替の換算、資料に無い理由づけ、発言の範囲を超える説明など）。書き手は原典で確かめてから台詞にし、確かめられないことは言わないか「資料に無い」と言う。
- 直したら、全体をもう一度この初見レビューに通す（毎回、新しいサブエージェントで。前のレビュー結果は渡さない）。**最大2周。** 2周目でも【致命的】が残れば、制作者に状況を報告して判断を仰ぐ。
- 合格したら、`python3 kl_dialogue.py review-pass --episode kl{NNN} --rounds N --report {OUT_PATH}` で記録する（台詞を変えたら記録は無効になり、`check` が「初見レビュー: 未実施（台詞が変わった）」と出す）。
