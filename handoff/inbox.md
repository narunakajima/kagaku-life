書き方: 1件1目的。件ごとに次の見出しで始める（ID は日付-3桁の連番）。
結果は `handoff/results/{ID}.md` に書かれる（このファイルが無い ID が未処理）。

```
## [2026-11-07-001] 件名
目的: …
完了条件: …
触ってよい範囲: …
```

確認なしで実行される範囲と、確認が残るものは `.claude/commands/kl-new.md`「進捗の報告」を見ること。
