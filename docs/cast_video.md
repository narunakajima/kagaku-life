# 立ち絵の動画化（大輔・沙織の待機ループと口パク）

> この文書は 2026-10-24 に CLAUDE.md から移した詳細・記録。本文は移す前のまま（見出しの名前も同じ。コードや手順書の「CLAUDE.md「〇〇」参照」は、ここの同名の節を指す）。

## 元の節「掛け合い形式への転換」より

**立ち絵の動画化（2026-10-17、パイロット）:** なるさんの指示（「SCのリポーターの動画のように、大輔と沙織を動画にしたい」）で、
samurai-chronicles の語り手 Tokio と同じ方式で、二人の立ち絵を静止画から**待機ループの動画**（息づかい・まばたき・わずかな頭の動き）にした。
- **作り方（`kl_cast_video.py`）:** 静止画の元（`assets/cast/raw/{role}_{expr}.png`）を Veo 3.1 fast の image-to-video（6秒・720p・9:16）に
  渡し（`gen`、素の動画は `assets/cast/raw/video/{role}_{expr}_veo.mp4`）、`post` で背景を抜いて往復ループの webm（VP9 alpha、静止画と同じ
  672x900）を `assets/cast/video/{role}_{expr}.webm` に作る。背景抜きは静止画（`kl_cast_gen.key_out`）と同じ式。使った区間とフレーム数は
  `assets/cast/video/loops.json`。費用の目安は1本6秒で約$0.9（12表情で約$11、2026-10時点の目安。価格表で確認）。
- **Veo の制約:** 6秒の後半でポーズが崩れる（上げた手・立てた指が下がる）ので、前半の動きの小さい区間だけを使う（`analyze` が自動で選ぶ。
  折り返し点は動きの小さい瞬間）。沙織 doubt は0.25〜2.25秒に「？」の記号が描き込まれたため、2.5〜4.2秒を手動で指定した。大輔 excited・
  surprised は動画の中で両手を上げたポーズに変わり、静止画（サムネイル）とポーズが少し違う。笑顔の指示は笑い出しやすい、音声は
  "Ambient audio: soft distant wind only." と書いて捨てる（SC と同じ）
- **合成（`kl_dialogue.build_sprite_tracks`、`kl_video_gen.overlay_dialogue`）:** 背景 → 字幕帯 → 大輔 → 沙織 → 字幕・名札・判定ラベル等
  （従来の状態トラック）の順に重ねる。立ち絵は役ごとの別トラックで、ループの何フレーム目を出すかは全体の時刻で決める（話し手が替わっても
  同じ表情なら動きが途切れない。表情が変わるときはカット）。位置・大きさ・聞いている側の暗さ（`INACTIVE_BRIGHTNESS`）・0.94倍は静止画と同じ
- **フォールバック:** webm の無い表情は静止画のまま（混在可）。`kl_video_gen.py --static-cast`（または `KL_STATIC_CAST=1`）で従来の静止画だけの
  動作に戻る。サムネイル（`composite_thumbnail_dialogue`）は静止画のまま
- **口パク（talk ループ、2026-10-17、なるさんが試作を見て承認）:** 表情ごとに「話しているループ」も作り（`kl_cast_video.py gen --kind talk` →
  `post --kind talk`、素の動画 `assets/cast/raw/video/{role}_{expr}_talk.mp4` → `assets/cast/video/{role}_{expr}_talk.webm`）、その役が
  **台詞を実際に話している間（行の `t0`〜`t0+dur`、状態の `talk_end`）だけ** talk ループ（明るい・通常の大きさ）に、台詞の合間は明るい待機ループ、
  聞いている間は暗い・0.94倍の待機ループにする。音声の大きさには合わせていない（Veo が描いた自然な口の開閉をそのまま使う）。talk と idle は
  それぞれ全体のフレーム番号 mod 自分の周期で位相を決める。切り替えはカット（同じ静止画から作っているので手・頭の位置はほぼ同じで、kl042 で
  跳ねは目立たなかった。目の開閉などの顔の状態は切り替わる）。talk ループの無い表情は待機ループのまま。プロンプトは待機用の「動かない・話さない」を
  「TALKING（口の開閉・小さなうなずき・まばたき）」に替え、表情と手の位置を保つ・笑わない・『？』などの記号を描かない、を明記した。
  使う区間は `analyze --kind talk` が口のあたりの動き（`MOUTH_BOX`、`loops.json` の `mouth_activity`）も見て選ぶが、**後半で手が下がる・
  記号が出る・目を閉じる点は待機と同じで、自動選定のまま使わず `sheet --kind talk` で必ず目で確認する**（初回は12本中4本を手動指定:
  大輔 excited 0.75〜3.8秒、surprised 0〜2.2秒、沙織 doubt 0.1〜2.1秒（2.2〜2.9秒に指先のピンクのにじみと目閉じ）、amused 0.71〜2.9秒
  （3秒過ぎから腕組みに変わる））。費用は12本で約$11（Veo 3.1 fast 6秒、目安）。生成は1回で全部成功した
- **「大輔のループがスムーズでない」への対処（2026-10-17、なるさんの指摘）:** 大輔の役トラックだけを取り出して測った原因は4つ。
  (1) 見た目の切り替えがすべてカットで、切り替え点のフレーム間差が 6〜38（区間内の動きは 0.01〜0.55）。大輔は台詞ごとに表情（手のポーズ）が
  替わるため本編で約100回あった。(2) Veo の大輔の待機ループはまばたき以外ほぼ静止（動きの中央値 0.01、talk は 0.55）で、話し始め・
  話し終わりで止まった体が急に動く／止まる。(3) 台詞の後に 0.2〜0.3秒だけ待機ループをはさんでから聞き手の表情に替わり、短い間に2回切り替わっていた。
  (4) talk ループの区間を口の動きで選んでいたため、往復の折り返しが頭・手の速い動きの途中に来て跳ね返っていた（excited talk で継ぎ目の差 3.1）。
  対処: (1) 切り替えに短いクロスフェード（`kl_dialogue.SPRITE_XFADE_FRAMES` 3フレーム、表情が変わるときは `SPRITE_XFADE_EXPR_FRAMES` 4フレーム。
  前の見た目を同じ位相で続けたトラックと重みのトラックを作り、アルファを掛けて（premultiply）`maskedmerge` で混ぜる）。
  (2) 待機ループに、ループの周期でちょうど1往復する呼吸（下端を支点にした 0.8% の縦の伸び縮み、`kl_cast_video.BREATH_AMP`）を焼き込む。
  (3) ヒステリシス: 台詞の後の 0.6秒未満の待機は talk のまま続ける（`TALK_HOLD_GAP`）。(4) talk の区間は口を除いた体の動きで折り返し点を選び直し、
  往復の折り返し点で2フレーム止める（`TURN_HOLD`、待機ループも同じ）。手が下がる・記号が出る部分は `post --range` で除き、`loops.json` に記録した。
  末尾を先頭に重ねる「つなぎループ」（`--loop xfade`）も用意したが、大輔の talk はうなずきで頭の位置が大きく変わり二重に見えるので既定は往復のまま
- **保留していた作り直し（2026-10-17、なるさんの指示「保留のやつはなんでやらない？」）:** Veo で9本作り直した（約$8.1、上限$12）。
  プロンプトに表情ごとの指示（`kl_cast_video.POSE_GUARD`: 入力画像の手の位置を言葉でも書いて保つ、目を開けたまま、記号を描かない）と、
  大輔の待機ループに肩・頭のゆっくりした揺れ（`IDLE_SWAY`）を加えた。候補は `gen --suffix _v2` で別名に作り、コンタクトシートで比べてから
  採用した（採用したものは元を `*_v1.mp4` として残した）。結果: 大輔 excited（待機・talk）と surprised（待機・talk）は手が静止画・サムネイルと
  一致した（静止画とのシルエットの重なり 0.87〜0.91 → 0.95〜0.997）。沙織 doubt の待機は「？」が出なくなり、ループが3.4秒→7.3秒に。
  大輔 deflated の待機は目を開けた苦笑いになった（2.7秒過ぎに目を細めるので区間は 0〜2.2秒）。大輔の待機の動きは neutral 0.12→0.50、
  convinced 0.12→0.46 に増えた。**thinking の待機は、作り直した方が動きが少なかったので初回を残した**（`loops.json` の `note` に理由）。
  Veo の作り直しでも、後半で手が下がるのは変わらない（excited は2.6秒、surprised は3秒前後）
- **名札のフェード（2026-10-17）:** 名札（名前＋肩書き、明るい／グレー）を状態トラックから立ち絵のトラックに移し、立ち絵と同じタイミング・
  同じ長さのクロスフェードで明暗が替わるようにした（それまでは立ち絵だけがフェードし、名札はカットで切り替わっていた）。位置・中身は同じ
  （`kl_dialogue.draw_nameplate`、立ち絵のキャンバスは名札まで入る幅に広げた）。`--static-cast` のときは従来どおり状態トラックに描く
- **オプション:** `kl_video_gen.py --no-talk`（または `KL_NO_TALK=1`）で口パクだけを止めて待機ループのみ、`--static-cast` で静止画のみ。
  生成時間は kl042 本編（8.5分）で静止画 397秒・待機ループ 406秒・口パク込み 594秒（口パク込みの計測中は別プロジェクトの ffmpeg が同時に動いていて実時間は割り増し。CPU時間では静止画 2315秒・待機 2374秒・口パク込み 2572秒で、静止画の約1.1倍）
