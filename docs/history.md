## 元の節「このプロジェクトについて」より: AI・ロボティクス限定の撤廃

**「AI・ロボティクス分野限定」という制約は2026-09-14に撤廃した。** 当初はAI・
ロボティクス分野の学術論文に限定していたが、kl021（ER-100/老化細胞の若返り
遺伝子治療、AI・ロボティクスを一切含まない分子生物学の研究）の選定を機に、
制作者の判断で恒久的に撤廃した。理由: 今後あらゆる科学分野の進展にAI・
ロボティクスが深く関わるようになるため、ジャンルを分野名で区切ること自体の
意味が薄れていく、という判断。経緯の詳細・議論の記録は下記「論文選定ロジック」
節を参照（当初は都度承認の「例外」運用として導入されたが、この撤廃により
例外ではなく通常の方針になった）。**番組の核心コンセプト（「信頼できる学術
論文が10年後の暮らしをどう変えるかを誠実に見せる」）自体は変更していない**
——変わったのは「対象を学術分野で絞り込むかどうか」だけであり、論文ベースの
検証可能性・誠実な科学解説というアイデンティティは今後も維持する。

## 元の節「構成 v3「使い道ラウンド」」より: 診断と決定（2026-10-17）

2026-10-26 に構成 v4 を入れたとき、CLAUDE.md から今のルール以外をここに移した（本文は変えていない）。

**構成 v3「使い道ラウンド」（2026-10-17、kl043以降。手順は `/kl-new` STEP2「構成 v3」）:** なるさんの「大輔の夢語りって必要？
前の設定が引きずられている気がする」を受けて、Opus が kl031〜kl042 の台本を診断し、なるさんが案(D)を選んだ。
- **診断:** 12話中11話に `dream` が2つあり、12話中9話が「大輔が言い過ぎる→沙織に崩される→『言い直す。想像してみてよ』で2つ目の dream」
  という同じ型だった（旧ルール「崩されたら言い直した夢をもう一度描く」が作っていた）。`life_scene`（誰が・いつ・何を）は旧形式の
  impact（「金曜の夜、〜が」「土曜の朝」「〜して待ってる」）の写し。dream の台詞はタイトル・hook_lines・ティザー・Shorts で一度も
  使われていなかった。価値があったのは「使い道を1つ置いて、それに一次資料が答えられるか確かめる」箇所（kl042 S08 の経理→画面操作の
  テスト4.83%、kl041 S12 の規約→個人情報を消してから入力）。視聴データは、Reporting API の生データが10/02までで掛け合い形式の回が
  1日分も無く、根拠にできなかった（`KL_diagnosis_2026-10-04.md` もリポジトリに無く、CLAUDE.md の要約を使った）
- **決定（なるさん）:** (1) 気になっているのは毎回の dream シーンで、人物の大輔は残す (2) 未来を絵で見せるのは必須ではない。
  dream は任意で1話に1つまで（現物がまだ無い回など、絵に価値があるときだけ） (3) 締めの固定文（大輔「次はどんな研究が、誰かの
  幸せな未来を運んでくるのか。」）はそのまま (4) 大輔の肩書き・口癖・自己紹介は kl043 から変える（`cast.json`: role_label「期待担当」、
  catchphrase「僕なら、これに使う」、intro・profile・site_profile。内部キー・声・立ち絵・名前・role_short「元エンジニア」は変えない）
- **規則（`"structure": "rounds_v3"`、`kl_dialogue.py check`）:** v2 の規則はすべて引き継ぐ。`life_scene` を必須から外し（使うなら dream の中だけ）、
  `use_case`（大輔の台詞、論点の中、同じ論点のその後に `check` があること）と `takeaway`（`verdict` で「誰が・何に・どんな条件で／いつ」）を必須にする。
  dream は1つまで。常套句「言い直」0回・「想像してみて」1回まで。沙織が譲る `turn`（大輔が正しかった論点）が無いと ⚠（不合格にはしない）
- kl031〜kl042 は作り直さない（kl041・kl042 は `rounds_v2` のまま check を通る）。`cast.json` は全体共通なので、kl042 以前の動画を
  作り直すと自己紹介の吹き出しだけ新しい文になる（台詞に名前・肩書きを入れていないので音声は作り直し不要）
