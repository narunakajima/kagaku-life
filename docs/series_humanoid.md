# ヒューマノイド定点観測シリーズ（2026-11-04〜）

根拠: `docs/channel_research_2026-11-04.md`（他チャンネル調査。登録者が伸びている小〜中規模の日本語チャンネルは、人型ロボなどの「物」を、値段・買える時期・どこで動いているかと組み合わせ、連番で続けている。「次も見たい」が登録の理由になるという推定）。
当チャンネルでも、登録が出たShorts 4本のうち3本がロボットだった。**題材だけで登録が増えるとは限らない**（調査報告の「証拠の質と限界」）ので、2〜3か月運用して、1,000再生あたりの登録（`/kl-analytics`）で判定する。

## 決めたこと（なるさんの指示で進め、細部は Opus の判断。変えるときは CLAUDE.md の該当箇所も直す）

- **名前:** 「人型ロボ定点観測」（仮）。共通の問いは「**人型ロボは、いつ・いくらで・どこに来る？**」
- **対象の回:** ジャンル `humanoid` で、ニュース採点の `series_fit` が4以上（値段・予約・出荷・導入先・稼働中の現場のどれかが、前回から動いたと一次資料で言える、またはシリーズの物差しに当てはめられる）の候補。`series_fit` が低い発表は、ヒューマノイドでも通常の回にする
- **毎回の物差し（3つ）:** ①値段 ②買える・借りられる時期 ③どこで動いているか。**一次資料に書いてあるものだけ**を言い、書いていない項目は「まだ発表されていない」と言う（推測で埋めない。数値・条件の捏造禁止）。それに判定の札（`verdict`）
- **回の構成:** 構成 v4 のまま。ただし回の頭（ティザーの直後、最初の論点の前の `setup`）で、**前回のシリーズ回の札と物差しを一言で振り返り、今回どれが動いたかを言う**（札が回をまたいで動くのが「次も見る」理由）。前回の札は `episodes/kl*.json` の `verdict` から取り、記憶で書かない。第1回は振り返りなしで、「今回から、人型ロボがいつ・いくらで来るかを、発表のたびに確かめます」と始める
- **枠:** 直近5話に**2話まで**をシリーズ回にする。連続2話にしない。シリーズにできる発表がない週は、無理に作らない（通常の回を作る）。ヒューマノイド以外のジャンルも混ぜる（ベスト3のジャンル条件・健康系の上限は変えない）
- **番号:** 公開順に 第1回、第2回…。初回は、この文書の日付（2026-11-04）以降に制作する最初のヒューマノイド回。過去回（kl033・kl036・kl040・kl049・kl051）は、さかのぼってシリーズに含めない
- **見せ方:** 概要欄の1行目の後に「人型ロボ定点観測 第N回」。再生リスト `humanoid` を入口にする。タイトルに入れるかは未決定（`youtube_title` は30〜40字で、末尾の「（11月時点）」と合わせると長いため。試すなら「…？（人型ロボ定点観測#2・11月時点）」の形）
- **Shorts:** 本編のシリーズ番号に触れない（1カット目の驚きを優先）。最後のカットは今のまま
